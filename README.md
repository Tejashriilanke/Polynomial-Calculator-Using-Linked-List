# Polynomial Calculator Using Linked List

## Project Overview
This project is a menu-driven Polynomial Calculator developed using Java. It uses a Singly Linked List to represent and perform different operations on polynomials.

## Features
- **Create Polynomial:** Create polynomials by entering coefficients and exponents.
- **Display Polynomial:** Display the polynomial in a readable mathematical format.
- **Polynomial Addition:** Add two polynomials.
- **Polynomial Subtraction:** Subtract one polynomial from another.
- **Polynomial Multiplication:** Multiply two polynomials.
- **Polynomial Division:** Divide one polynomial by another and calculate the quotient and remainder.
- **Polynomial Evaluation:** Evaluate a polynomial for a given value of x.

## Data Structure Used
**Singly Linked List**

Each node stores:
- Coefficient
- Exponent
- Next pointer

## How to Run

1. Make sure Java JDK is installed.
2. Open the project folder in a terminal.
3. Compile the program:

```bash
javac PolynomialCalculator.java
```

4. Run the program:

```bash
java PolynomialCalculator
```
